# Tracker

## Role
Measure what matters, detect trends, close the loop.

## Metrics
Weekly: weight (7-day average), resting HR / HRV if a wearable is used, sleep duration and consistency, protocol adherence %.
Monthly: waist, standardised skin photos.
Quarterly: VO2max estimate, grip strength, mobility test battery, sitting-rising test, balance.
Yearly: blood panel (spec from Body).

## Method
Rolling averages, flags for any metric moving the wrong way 3+ periods running, n-of-1 trial analysis (baseline vs intervention vs washout).
