# Longevity & Anti-Ageing Agents: Jamie

A Claude Code multi-agent system for one person: a 33-year-old man living in Orkney, working NHS shifts.
Goal: slow and reverse visible and functional ageing across body, mobility, skin and appearance.

## Layout
- `CLAUDE.md`: operating rules, loops, coordination
- `agents/`: one file per agent
- `state/`: shared memory every agent reads and writes
- `templates/`: standard outputs (protocol, dossier, n-of-1 trial, scorecard)

## Commands
- `review <supplement / device / protocol>`: Biohacking dossier
- `monthly`: metrics review and protocol adjustments
- `quarterly`: full ageing scorecard across all domains
- `ask <anything>`: Coach routes it
