## Staggering rules (so Tracker can attribute effects)
- **≤3 new changes per 4-week month**, introduced on Mondays, one per week at most.
- **Same metric family ≥3 weeks apart.** Skin changes are spaced 4 weeks apart on the redness score; Body changes are spaced on the strength vs cardio metrics.
- Each change has **one primary metric** and an **attribution window** (the weeks before the next change touching that metric).
- Weeks with no new change: Week 3, Week 4, Week 8 (Christmas + gate), Weeks 12–13 (consolidate + retest).
- Missed twice running → Coach simplifies it, attaches it to an existing habit, or cuts it.
